# 📊 Simulador de Interés Compuesto y DCA: Análisis de Portafolios vs S&P 500

Este proyecto es un ejercicio académico de ciencia de datos aplicado a las finanzas personales. Modela el impacto a largo plazo del interés compuesto y el DCA comparando estructuras de portafolio frente al S&P 500.

La tesis pública que corre en eToro es el **Portafolio 1**: SPYG 35%, SMH 20%, BRK.B 20%, IEMG 15%, VTI 10%.

## Escenarios

* **Portafolio 1:** Core (el de @Andalejo1109).
* **Portafolio 2:** Más concentrado, sin VTI.
* **Portafolio 3:** Benchmark S&P 500 (~12% anual).
